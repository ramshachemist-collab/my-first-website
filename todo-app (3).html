Test that your data is saved
  1. Add a task, then press F5 (or Ctrl/Cmd+R). It is still there.
  2. Hard-reload with Ctrl+Shift+R (Cmd+Shift+R on Mac). The task remains.
  3. Complete a task, close the tab, reopen the file. It stays struck through.
  4. Use “Show saved data” in the sidebar to view the raw JSON stored in your browser.
Private/incognito windows clear storage on close, and file:// pages in some browsers keep separate storage per file location. Always open the same file from the same place.
